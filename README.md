# Provit

Wochenplaner mit 300 Rezepten, Preisvergleich (Aldi, Lidl, Rewe, Edeka, Penny) und Einkaufsliste.

**App öffnen:** über die GitHub-Pages-Adresse dieses Repositorys (Settings → Pages).

## Auf dem iPhone als App
1. Adresse in **Safari** öffnen.
2. Unten auf **Teilen** → **Zum Home-Bildschirm**.
3. Provit ab jetzt nur noch über das Symbol öffnen (das Symbol hat einen eigenen Speicher).

## Daten übertragen
Profil → „Daten sichern / übertragen“ → Sicherungscode kopieren. Auf dem neuen Gerät im Begrüßungsbildschirm „Mit Sicherungscode wiederherstellen“ wählen.

## Update einspielen
Neue `index.html` (und ggf. `sw.js`) über „Add file → Upload files“ hochladen und mit „Commit changes“ bestätigen. Nach 1–2 Minuten ist die neue Version online.
